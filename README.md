# 🤖 Face Recognition App

A simple Python app that recognizes faces and greets people by name!

## ✅ What it does:
- **Known person**: "Hello [Name]!" 
- **Unknown person**: "I do not know you. Please introduce yourself."
- **Add new people**: Scan and save faces to database

## 🚀 Requirements
- Python 3.10
- Camera/Webcam

## 🔧 Installation

```bash
pip install -r requirements.txt
```

## 🚀 Usage

### Command Line Version
```bash
python face_recognition_app.py
```

### Interactive Demo
```bash
python demo.py
```

## 🎮 Controls
- Press `q` to quit
- Press `a` to add new person
- Look at camera for recognition

## 📁 Files
- `face_recognition_app.py` - Main command-line app
- `demo.py` - Interactive demo
- `face_database_mp.pkl` - Face database (auto-created)
